定义

云是什么应用？

云（Gureum）是在 Android 和 iOS 上使用的绕过网站拦截的应用。网站被拦截打不开时，它在这台设备上更换 DNS，并把网站名（SNI）拆开再发，帮助一部分 HTTPS 连接。它不改变 IP 或国家，不打开 HTTPS 内容，也不把流量送到远程 VPN 服务器。它不是所有被拦截的网站都能打开。

FAQ

绕过网站拦截，常见问题

什么是绕过网站拦截的应用？

它是帮被拦截的网站打开的应用。网站名（SNI）导致 HTTPS 连接断开时，云在这台设备上更换 DNS，并把这个名字拆开再发。它不改变 IP，也不把流量送到远程 VPN 服务器。

它帮助哪些拦截？

它帮助一部分因为网站名（SNI）而断开的 HTTPS 连接。针对 IP 或游戏服务器的拦截，以及广告拦截，它都不做。

网站被拦截了为什么打不开？

要看拦截在哪一层。可能是地址查询（DNS）被拦、IP 被拦、游戏服务器被拦、设备上自设的拦截，或网站名（SNI）导致 HTTPS 连接断开。云帮的是一部分因为网站名而断开的连接。

出现警告页的网站也能打开吗？

因为网站名（SNI）出现的警告，它能帮上忙。它会更换 DNS，并把那个名字拆开再发。针对 IP 或游戏服务器的拦截，它打不开。

和普通 VPN 有什么不同？

远程 VPN 可以把流量送到 VPN 服务器，并改变 IP 或路径。云不把流量送到那台服务器。它只在这台设备上更换 DNS，并处理网站名（SNI）。IP 和国家都不变。

不用 VPN 也能绕过网站拦截吗？

云不使用远程 VPN 服务器，在这台设备上更换 DNS，并把网站名（SNI）拆开再发，帮一部分因为这个名字而断开的 HTTPS 连接。针对 IP 或游戏服务器的拦截，它打不开。

IP 地址会变吗？

不会。云不改变 IP，也不改变国家。它不会把流量送到海外 VPN 服务器。

也会拦截广告吗？

不会。云不是广告拦截应用。它做的是更换 DNS 和拆开网站名（SNI）。

会看 HTTPS 内容吗？

不会。云不检查也不解密 HTTPS 内容。它处理的是 DNS，以及连接开始时发出的网站名（SNI）。

把网站名拆开是什么意思？

HTTPS 连接开始时，云不会一次发完网站名（SNI），而是拆开再发。这样能帮一部分因为这个名字而断开的连接，HTTPS 通信内容不检查也不解密。

被拦截的网站还是打不开怎么办？

打开云之后还是打不开，那可能不是网站名（SNI）的拦截。网站地址、游戏服务器，或你自己在设备上设的拦截，云都打不开。只想换 DNS 试试，就在 Cloudflare、Google、Quad9 里选。

网站被拦截打不开，该怎么办？

先看其他网站还能不能打开。只有一个网站出现警告页，地址又是 HTTPS，那可能是网站名（SNI）导致断开。这时打开云，再试一次那个网站。

手机上怎么绕过 HTTPS 拦截？

打开云并允许一次权限，然后点中间的云。之后它会在这台设备上更换 DNS，连接开始时把网站名（SNI）拆开再发。

可以选哪些 DNS？

可以选 Cloudflare、Google 或 Quad9。地址查询会发到所选 DNS。

Cloudflare、Google、Quad9 该选哪个？

三个都能查询地址。选哪个可以看各家提供方的政策，云只把查询发给你选的那个 DNS。访问过的网站名不会发给 Analytics。

开着会变慢吗？

流量不经过远程 VPN 服务器，所以路径不会像远程 VPN 那样变长。实际速度取决于网络和你选的 DNS。

需要账号吗？

不需要。云不用注册就能打开。

Android 和 iPhone 都能用吗？

支持 Android 和 iOS。商店链接准备好之后会放在这个页面上。

应用代码公开吗？

只公开介绍页。应用代码不公开。

会发送访问过的网站名吗？

不会。访问过的网站名和手动填写的 DNS 地址不会发给 Google Analytics。发出去的只有保护是否开启和所选 DNS 类型，广告个性化是关闭的。地址查询会发到所选 DNS。
