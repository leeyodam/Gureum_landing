FAQ

绕过网站拦截，常见问题

什么是绕过网站拦截的应用？

它是帮被拦截的网站打开的应用。网站名（SNI）导致 HTTPS 连接断开时，云在这台设备上更换 DNS，并把这个名字拆开再发。它不改变 IP，也不把流量送到远程 VPN 服务器。

它帮助哪些拦截？

它帮助一部分因为网站名（SNI）而断开的 HTTPS 连接。针对 IP 或游戏服务器的拦截，以及广告拦截，它都不做。

网站被拦截了为什么打不开？

要看拦截在哪一层。可能是地址查询（DNS）被拦、IP 被拦、游戏服务器被拦、设备上自设的拦截，或网站名（SNI）导致 HTTPS 连接断开。云帮的是一部分因为网站名而断开的连接。

出现警告页的网站也能打开吗？

因为网站名（SNI）出现的警告，它能帮上忙。它会更换 DNS，并把那个名字拆开再发。针对 IP 或游戏服务器的拦截，它打不开。

不用 VPN 也能绕过网站拦截吗？

云不使用远程 VPN 服务器，在这台设备上更换 DNS，并把网站名（SNI）拆开再发，帮一部分因为这个名字而断开的 HTTPS 连接。针对 IP 或游戏服务器的拦截，它打不开。

会看 HTTPS 内容吗？

不会。云不检查也不解密 HTTPS 内容。它处理的是 DNS，以及连接开始时发出的网站名（SNI）。
