FAQ

Site blocking bypass questions

What is a site blocking bypass app?

It is an app that helps a blocked site open. When an HTTPS connection drops because of the site name (SNI), Gureum changes DNS on the device and sends that name in pieces. It does not change your IP or send traffic to a remote VPN server.

Which blocks does it help with?

It helps with some HTTPS blocks that use the site name (SNI). It does not open blocks aimed at an IP address or a game server, and it does not block ads.

Why won't a blocked site open?

It depends on where the block sits. The lookup (DNS) can be blocked, the IP can be blocked, a game server can be blocked, the device can block it, or the HTTPS connection can drop over the site name (SNI). Gureum helps with some drops caused by the site name.

Does it open sites that show a warning page?

Yes, when the warning appears because of the site name (SNI). It changes DNS and sends that name in pieces. It does not open blocks aimed at an IP address or a game server.

Can I bypass a site block without a VPN?

Gureum uses no remote VPN server. It changes DNS on this device and sends the site name (SNI) in pieces, which helps with some HTTPS connections that drop because of that name. It does not open blocks aimed at an IP address or a game server.

Does it read HTTPS?

No. Gureum does not open or decrypt HTTPS contents. It handles DNS and the site name (SNI) sent when a connection starts.
